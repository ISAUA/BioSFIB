# 已完成分析的表格快照

这里是从已有正式结果整理的 74 个文件，不包含原始表达矩阵、模型权重或新实验结果。59份科学数据表/背景文件保持原字节；15份元数据 manifest 仅将本机绝对路径改为 source_archive/ 相对来源引用。发布文件的 SHA256、大小，以及脱敏前原始元数据的 source_sha256/source_bytes 均见 `manifest.json`；统计参数、数据库版本与结果未改。

- `benchmark/`：合并指标长表，可独立重绘指标图；`source_file` 是当时的来源记录，不是发布版运行路径。
- `enrichment/`：MISAR 八切片和 P22 四测量的显著富集表、输入 QC、背景基因、marker 输入和原 manifest。
- `gene_peak/`：P22 ATAC、MISAR E15.5-S1/E18.5-S1 的完整显著关联表、原位点图选中关联及摘要；三者相同的 GTF 解析表只存一份。

元数据中的 source_archive/、旧目录名和图名仅用于历史溯源，**不会被脚本当作默认运行路径**，也不代表仓库包含对应原始数据。实际运行输入由 analysis 配置/命令指定。

未打包 g:Profiler 的历史 API 响应缓存、完整非显著结果、候选关联大表、原始 GTF、原始数据和外部方法 H5AD。缺少缓存时可以从显著表重建汇总，但不能声称重现当时的全部 API 查询。在线重算须记录新的数据库版本，不能覆盖这些快照。

这些文件只用于核查、统计汇总和下游展示，不可作为模型训练输入。
